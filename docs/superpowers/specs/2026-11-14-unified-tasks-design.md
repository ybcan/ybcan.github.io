# 统一目标、项目和任务
用户已采纳三类执行对象：目标→项目→任务。事项改称项目，计划改为同一批任务的时间安排视图，待办为未完成任务视图；学习成果、方案建议作为关联资料。

迁移保留ID、完成状态、来源、历史、日期和采纳状态。项目步骤转为规范任务，原步骤列表停止独立执行；有稳定迁移映射，重复导入和删除后刷新不重复生成。明确行动型旧计划转成任务；AI路线/含义不明确的旧计划保留方案资料，可明确转成任务或里程碑，采纳不自动开工。方法/想法按资料呈现，不计入执行项目。旧资料元数据保留以便溯源，旧plans集合仅兼容存放资料，不再作为执行看板。

项目详情、任务页、计划视图显示同一任务ID，完成状态同步。任务可设置主项目、安排日、截止日和优先级；候选任务与正式待办分开；临时任务可未归属。项目进度从任务计算。计划视图按安排日期组织，旧计划看板及独立步骤编辑器退出执行入口。保留当前驾驶舱/目标树、归档、实验空间随手记、编辑删除、独立文件备份等能力。

支持旧v1/v2备份和现有归档导入，新备份版本3。迁移在浏览器本地进行，写入失败保留可导出数据与原始存储。自动升级不上传个人数据。将来源不明确的旧计划归为待确认资料，是实现默认选择，避免编造动作或执行状态。源码版本0.5.0。
